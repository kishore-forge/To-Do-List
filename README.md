# 📝 To-Do List

A simple, clean, and responsive **To-Do List web application** built using **HTML, CSS, and JavaScript**.
This project helps users organize their daily tasks, track completed work, and manage their tasks easily through an interactive interface.

## ⚙️ How It Works

### 1. Add a Task

Enter your task in the input field and click the **Add** button.

### 2. Complete a Task

Click the checkbox next to a task to mark it as completed.

The task text will automatically receive a **strike-through effect**.

### 3. Delete a Task

Use the delete option to remove a task from the list.

### 4. Task Counter

The application keeps track of the number of remaining tasks and updates the count automatically whenever a task is added, completed, or deleted.

## 💻 Getting Started

### Prerequisites

You only need:

* A modern web browser
* VS Code or any other code editor

### Installation

Clone the repository:

```bash
git clone https://github.com/kishore-forge/To-Do-List.git
```

Navigate to the project folder:

```bash
cd todo-list
```

Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code for a better development experience.
